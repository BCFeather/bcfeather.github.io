Deep learning has made single-chain protein structure prediction close to routine, and the same methods stall when the target is a homo-oligomer. A complex of six identical subunits has six times the sequence of one chain, and the pair representations that modern predictors build grow with the square of that length, so memory and time grow far faster than the number of chains. Complex predictors solve that by co-folding the chains with pair features that encode which residue of one chain sits near which residue of another, and the representation that results is what grows so fast.

A second problem is bookkeeping. The subunits are identical, so any assignment of a residue in one chain to a position in the model is as good as the assignment to its symmetric partner, and a training loss that does not know about the symmetry sees many correct answers as different ones and learns from the disagreement. An equivariant network can absorb the symmetry if the invariance is built into its operations, and the architecture here does exactly that rather than leaving it to the loss.

A preprint posted to arXiv on 7 March 2024 addresses both with a single design. The authors build SGNet, which extracts features from one subunit only and then generates the full assembly through a symmetry module, so the expensive part of the computation is done once and not once per chain. The feature extractor is an ordinary single-chain predictor; the novelty sits in what happens to its output afterwards.

The symmetry module is where the modelling happens. Given the point group of the assembly, cyclic or dihedral, the module places copies of the folded subunit at the right rotations and translations, and it does so consistently across all the symmetry types rather than handling one group at a time. Cyclic groups place copies around a common axis, dihedral groups add a mirrored copy across a plane, and both are produced by composing a rotation with the base fold, which is why one module covers every global symmetry type.

Consistency is what fixes the supervision. Because every copy is generated by the same rule, the loss is evaluated once on a canonical subunit and the ambiguity that identical chains create disappears, which is the training fix that the architecture makes possible.

The benchmark supports the approach. On a set of symmetrical complexes the method improves on predictors that treat the assembly as a single long chain, and it does so with a memory footprint that does not grow with the number of subunits. The memory saving is the point that matters most for large assemblies, since a hexamer at 400 residues per chain would otherwise need a pair representation forty times the size of a monomer run.

What the design assumes is the hard part in practice. A method that folds one chain and copies it will be right when the subunits really are identical and will fail when a complex is pseudo-symmetric, with subunits that differ slightly in conformation, and a model that flags the pseudosymmetric case before folding, from differences in the sequence alone, would be the useful companion to this one.
