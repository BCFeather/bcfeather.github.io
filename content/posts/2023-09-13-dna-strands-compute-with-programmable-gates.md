A DNA computer uses strands as its wires and its gates, and the field's circuits have been small. An array that can be programmed to implement different functions is the step from a demonstration to an architecture. Built in *Nature* on 13 September 2023, the array is assembled from DNA origami tiles, configured by input strands, and run as circuits that implement logic and arithmetic.

Programmability is the advance. A fixed circuit does one function, and an array whose gates are set by strands does many, so the configuration rather than the wiring carries the computation. The input's encoding is the programme itself, because a set of strands stands for a value and the gates transform it according to their sequences.

Self-assembly supplies the fabrication. A tile carries a gate and a connector, and tiles assemble into a lattice whose connections the strands specify; connectors are the wiring, since a tile's edge binds one specific neighbour and the set of edges is the circuit's topology. Speed is the weakness, and the authors are candid about it. A DNA reaction takes minutes and a computation is a sequence of them, so the architecture is slow against silicon by orders of magnitude. That comparison is unfair and still useful, because it identifies a niche rather than a competitor.

Application is not arithmetic. A slow circuit earns its place where computation couples to molecular recognition, and a diagnostic deciding on a set of markers is the case the authors have in mind. Error rate sets the constraint. A mispaired strand produces a wrong output, and orthogonal sequence design with redundancy is what keeps the circuit reliable; leakage is that failure mode, since a gate reacting with the wrong input emits a spurious signal.

Scale sets the limitation, because a lattice of a few hundred tiles is a modest circuit and a larger array needs fabrication the field has not shown. A general-purpose computer is the claim not made here, since a platform running a few circuits still waits for a compiler for arbitrary functions.

Molecular computing gains an architecture rather than a circuit, since the field's results have been individual computations and an array is a substrate for many. Gate logic rests on strand displacement, where an invading strand displaces an output from a duplex, and that displacement is the reaction a gate implements.

Readout is the interface between a circuit and its user, because an output has to be detected and fluorescence or a gel is the laboratory method available. A gate array that ran arithmetic on a set of markers would be the diagnostic the architecture is aiming at, and the coupling of computation to recognition is what silicon cannot do. A compiler that mapped a desired function onto a pattern of tiles and strands would be the platform's missing layer, and without one every circuit is still designed by hand.
