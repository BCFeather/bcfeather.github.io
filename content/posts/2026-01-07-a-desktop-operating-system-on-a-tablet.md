Tablets have run desktop operating systems before, badly: a mobile shell with a keyboard attached and a file manager bolted on. The device shown at this month's consumer electronics show runs the desktop system itself, with a window manager, a real file system, and applications compiled for the architecture rather than ported from a phone. Priced at 899 dollars with a keyboard in the box, it is aimed at the buyer who wants one device and has been told for fifteen years that the category does not exist.

Thermals decide the design. A desktop processor in a 7 millimetre chassis sustains about 12 watts before the surface exceeds the touch comfort limit, which is why the device ships with a fanless design and a performance curve that throttles at 8 watts. The same chip in a laptop runs at 28 watts. Benchmarks in the launch materials come from the laptop configuration, which is a fair reading of the silicon and an unfair reading of the tablet.

Software compatibility is the actual claim. Applications that expect a pointer, a menu bar and a window that can be resized do not work on a mobile shell, and the alternative has been remote streaming from a server. Running them locally requires an emulation layer for the legacy binary format and native builds for the rest, and the device ships with both, at a cost in memory: 16 gigabytes of unified memory is the minimum for the configuration that reviewers were given.

Battery arithmetic is unflattering. The 58 watt-hour cell delivers about six hours of mixed work at the sustained power the chassis allows, against ten hours for a laptop with the same cell because the laptop can run the same workloads at a lower clock. A device that runs desktop software must budget for desktop power.

The market question is who buys it. Enterprise buyers have wanted a single device for a decade and have been blocked by management tooling that assumes a desktop operating system; this device clears that blocker. Consumers have been blocked by price and by the fact that a phone plus a cheap laptop costs less.

Whether the category grows depends on the next two years of software. A desktop system on a tablet is only as good as the applications that run natively on it, and the launch list is short: a browser, an office suite, two image editors and a development environment. The rest run through emulation and pay for it in battery.

Application compatibility is the claim that will be tested by users. The launch list is short, and the emulation layer runs older binaries at roughly 70 per cent of native speed on this hardware, which is adequate for office work and poor for compilation or rendering. Buyers who expect a laptop replacement will find the gap in exactly the tasks that made them want one.

Input devices are the second test. A desktop system expects a pointer that can land on a 6-pixel scrollbar, and a finger cannot; the device ships with a stylus and a trackpad cover, which is an admission that the touch layer is secondary.

Reading the announcement as a hardware event misses the point. The hardware is a known quantity: a fanless chassis, a large cell and a good screen. The decision that matters is to ship a system that expects a mouse and a file system, which is a software commitment that a mobile-first company would not make.
