# Hugo build

The site is generated by Hugo 0.152 (extended). Jekyll is no longer involved in
building or publishing it.

```sh
hugo --buildFuture --gc -d public     # ~16 s for 1,499 posts
python3 scripts/gen-json.py public    # reshapes public/index.json into the three indexes below
```

or simply

```sh
GITHUB_TOKEN=... bash scripts/build-and-publish.sh
```

which builds, generates the indexes, force-pushes `public/` to the `gh-pages`
branch and dispatches the `publish-prebuilt.yml` workflow that uploads that
artifact. GitHub Actions never renders the site.

## Layout

| Path | Role |
| --- | --- |
| `content/posts/*.md` | 1,499 posts, one per `_posts` file; `slug` is pinned to the Jekyll slug so every URL matches the old site |
| `content/archives/` | `/archives/`, `/archives/<year>/`, `/archives/<year>-<month>/` |
| `content/{about,faq,license,copyright}.md` | tab and utility pages |
| `layouts/` | Chirpy-compatible templates: base, home, post, page, taxonomy/term, the three archive levels, 404 |
| `static/assets/{css,js/dist,img}` | the compiled Chirpy CSS, the theme's dist JS and the favicons, copied from the last Jekyll build |
| `layouts/index.json` | build-time dump of every post; deleted after `gen-json.py` splits it |
| `layouts/index.rss.xml` | Atom feed, latest 10 posts, written to `/feed.xml` |

## Generated indexes

| URL | Shape |
| --- | --- |
| `/assets/js/data/search.json` | `[{title,url,categories,tags,date,content}]`, content clipped to 160 chars |
| `/assets/data/featured.json` | `{"p":[{u,t,d,s}]}` for the home carousel |
| `/assets/data/posts-index.json` | `{"n","c","a","b","p":[{t,u,d}]}` for the sidebar Today panel |

## Parity checks done

* every non-pagination URL of the last Jekyll build exists in the Hugo build
  (1,499 post pages, 65 archive pages, taxonomies, tabs, utility pages); the only
  extra path is `/posts/` which is left unrendered;
* home, post, archives (three levels), categories and a category term page were
  screenshot-compared against the Jekyll output at 1440 px and 390 px;
* `sw.js`, the sidebar Today panel, the related-posts strip, post navigation,
  utterances comments and the SimpleJekyllSearch overlay all run against the
  Hugo output.

## Legacy files

`_posts/`, `_layouts/`, `_includes/`, `_tabs/`, `archives/`, `_config.yml` and
`Gemfile*` are the Jekyll sources, kept untouched for reference. They are no
longer read by any build. `_site/` is the last Jekyll output.
